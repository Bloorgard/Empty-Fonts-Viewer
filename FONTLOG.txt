FONTLOG for the VTF Viewer font
===============================

This file provides detailed information on the VTF Viewer font family.
This information should be distributed along with the VTF Viewer fonts
and any derivative works.


Basic Font Information
----------------------

VTF Viewer is an experimental display typeface by Pustota, supporting
Latin and Cyrillic. It is developed in Glyphs and distributed here in
OTF and web (WOFF, WOFF2) formats.
